### Known issue: dev server with Node.js 22+ and Vercel adapter

If the E2E tests fail because the dev server (started automatically by
Playwright via `npm run dev`) fails to serve pages (blank page or 500 error),
this is the known Node.js 22+ / @astrojs/vercel esbuild compatibility issue.

To fix this, check `astro.config.mjs`. If the `vite.esbuild.target` setting
is missing, add it now:

```js
export default defineConfig({
  // ... existing config ...
  vite: {
    esbuild: {
      target: 'es2022',
    },
  },
  // ...
})
```

After adding this, run `npm run dev`, visit http://localhost:4321, and confirm
pages render. Then re-run `npm run test:e2e`.

If `npm run dev` still has issues after the Vite fix, update `playwright.config.ts`
to use a build-based server instead of the dev server:

```ts
webServer: {
  command: 'npm run build && npx serve@latest .vercel/output/static -p 4321',
  url: 'http://localhost:4321',
  reuseExistingServer: false,
  timeout: 120 * 1000, // build can take ~30s
},
```

Also ensure `package.json` has the `dev:build` script for users:
```json
"dev:build": "npm run build && npx serve@latest .vercel/output/static -p 4321"
```
