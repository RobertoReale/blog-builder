## STEP 2 — Inventory available Claude Code skills in this session

The following skills are built into Claude Code and available right now.
Evaluate which are most valuable for an Astro static blog project:

  verify          — Launch the app in a real browser and confirm a change works.
                    High value: catches regressions that build passes miss.

  run             — Start the dev server and screenshot the result.
                    High value: confirms the golden path after big changes.

  code-review     — Diff-level correctness + quality review before merging.
                    High value: catches logic errors and unnecessary complexity.

  security-review — Audit pending changes for OWASP-style vulnerabilities.
                    Medium value for a static blog (no auth/DB), still useful.

  simplify        — Remove duplication and unnecessary complexity from changed code.
                    Medium value: good to run after large feature additions.

  fewer-permission-prompts — Scan transcripts and add allowlists to reduce
                    interruptions. High value: run once early in the project.

  schedule        — Create recurring automated agents on a cron schedule.
                    Low value unless the user wants scheduled content or checks.

  loop            — Run a command on a repeating interval.
                    Low value unless live-polling during a long build.
