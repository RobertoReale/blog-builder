### Logic

For a given article, find related articles by:
1. Collecting all other published articles
2. Scoring each by number of shared tags with the current article
3. Filtering out any with 0 shared tags
4. Sorting by score descending, then by date descending as tiebreaker
5. Taking the top 3

If no related articles exist: render nothing. No empty section, no fallback.

### Wire up in getStaticPaths

CRITICAL — there is only ONE getStaticPaths in src/pages/article/[slug].astro.
Astro does not allow two. If Feature 04 (Series) has already been implemented,
it ALSO computes data inside this same getStaticPaths and returns it in `props`
(e.g. `seriesParts`). Do NOT paste a second `return allPublished.map(...)` that
overwrites it — that silently drops the series prop and breaks SeriesNav.
EXTEND the existing map: compute `related` alongside whatever Feature 04 already
computes, and return BOTH in the same props object.

The article-level computation to add (merge into the existing per-entry map):

```ts
// allPublished is already fetched at the top of getStaticPaths.
// Inside the existing `allPublished.map(entry => { ... })`:

const related = allPublished
  .filter(other => other.slug !== entry.slug)
  .map(other => ({
    ...other,
    sharedTags: other.data.tags.filter(t => entry.data.tags.includes(t)).length
  }))
  .filter(other => other.sharedTags > 0)
  .sort((a, b) => b.sharedTags - a.sharedTags ||
    b.data.date.getTime() - a.data.date.getTime())
  .slice(0, 3)
  .map(r => ({
    title: r.data.title,
    slug: r.slug,
    date: r.data.date,
    tags: r.data.tags,
    description: r.data.description,
    readingTime: getReadingTime(r.body),
  }))

return {
  params: { slug: entry.slug },
  // Keep every prop the page already needs. If Feature 04 added seriesParts,
  // it MUST remain here — only `related` is new.
  props: { entry, related /*, seriesParts (from Feature 04, if present) */ }
}
```

If Feature 04 is NOT yet implemented, the props object is simply
`{ entry, related }`. Either way, never replace props you didn't author.

Pass `related` as a prop to the page component,
then pass it to `<RelatedArticles articles={related} />`.
