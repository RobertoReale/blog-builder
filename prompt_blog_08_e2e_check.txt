### Known issue: dev server fails with "Expected } but found :"

If the E2E tests fail because the dev server (started automatically by
Playwright via `npm run dev`) fails to serve pages (blank page, 500 error,
or `Expected "}" but found ":"` in the console), the most common cause is
an `@astrojs/react` version mismatch.

**Check first:** run `npm list @astrojs/react` and verify the installed version
is compatible with Astro 4 (major versions of `@astrojs/react` track Astro
major versions — v5+ targets Astro 5 and breaks Astro 4). If a wrong version
is installed, downgrade:

```bash
npm install @astrojs/react@^4
```

After fixing the React version, re-run `npm run dev` and confirm pages render.
Then re-run `npm run test:e2e`.

If `npm run dev` still has issues after verifying the React version, search
online for current known issues with your exact package versions before
proceeding to the fallback below. Update `playwright.config.ts`
to use a build-based server instead of the dev server:

```ts
webServer: {
  command: 'npm run build && npx serve@latest .vercel/output/static -p 4321',
  url: 'http://localhost:4321',
  reuseExistingServer: false,
  timeout: 120 * 1000, // build can take ~30s
},
```

Also ensure `package.json` has the `dev:build` script for users:
```json
"dev:build": "npm run build && npx serve@latest .vercel/output/static -p 4321"
```
